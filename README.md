# Friend Levels

Real friend levels in the friend list and Group Manager.

Shows real levels for friends in the friend list and Group Manager, remembered from your group and clan (the game sends level 1 when it does not know).

An add-on for [ROSE Mod Launcher](https://github.com/Zurnny/Rose_Mod_Launcher), for the game's **default** UI. The [Steampunk UI](https://github.com/Zurnny/SteamPunk) theme already includes this, so you don't need it with Steampunk (if both are on, Steampunk's files win).

## Install
1. Download this repo (Code > Download ZIP) and open it.
2. Copy the **Friend Levels** folder into `Launcher Mods` in your ROSE Online folder.
3. Open the launcher, press **Mods**, tick **Friend Levels**, and restart the game.

It updates itself from this repo whenever the launcher opens.

## Files it changes
- `Data/ui/themes/rose/game/friend_list.html`
- `Data/ui/themes/rose/game/group_manager.html`

Turning it off in the launcher puts the game's own files back.
